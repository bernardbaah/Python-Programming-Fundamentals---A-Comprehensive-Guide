# Python Programming Fundamentals — A Comprehensive Guide

**Author:** Bernard Baah  
**Series:** Filly Coder

A web-based reader for *Python Programming Fundamentals: A Comprehensive Guide*.

## Running Locally

**Requirements:** Python 3.13+

```bash
# Install dependencies
pip install flask pymupdf

# Place the book PDF in the project root as:
# Python_Fundamentals_Updated.pdf

# Start the server
python app.py
```

Then open [http://localhost:5000](http://localhost:5000) in your browser.

## Project Structure

```
├── app.py           # Flask web server
├── viewer.html      # PDF viewer UI
├── pyproject.toml   # Python dependencies
└── README.md
```

## About the Book

A comprehensive introduction to Python programming covering:
- Syntax and semantics
- Data structures and algorithms
- File I/O, exceptions, and debugging
- Web development basics

Ideal for beginners, students, and professionals seeking a solid foundation in Python.
